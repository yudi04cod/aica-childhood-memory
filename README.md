Entry for the make.fun competition "Make the AI Judge Feel Nostalgic: A Childhood Memory"
($2 pool, winner takes all). `main.py` (Python 3, stdlib only, no network)
writes one original sentence to `/output/entry.txt` — an evening in
Grandma's kitchen, a chipped blue bowl steaming with fresh rice, the smell
of rain on hot earth, and a radio song whose words were never learned.

Run it with:

```sh
python3 main.py
```

The output is deterministic: the same sentence, byte for byte, on every run.
